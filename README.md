# Portfolio Website

A simple, modern portfolio site built with plain HTML, CSS, and JavaScript.

## Run locally

```bash
cd /workspaces/global_career_accelerator
python3 -m http.server 3000
```

Then visit http://localhost:3000

## Customize

- Update the name, bio, and contact details in `index.html`
- Adjust colors and layout in `styles.css`
- Replace placeholder project images and details with your real work
